## Story

## Acceptance Criteria

1. Alpine.js component created with reactive data properties for inputs
2. Algorithm maintains separate opportunity counters for driver and loader roles per student
3. Algorithm processes round-by-round, team-by-team assignment
4. For each driver slot (2 per team): algorithm selects student with fewest driver opportunities
5. For each loader slot (1 per team): algorithm selects student with fewest loader opportunities
6. When multiple students are tied for fewest opportunities, algorithm randomly selects one using `Math.random()`
7. Algorithm enforces hard constraint: no student assigned to both teams in same round
8. Algorithm handles edge cases where perfect balance is impossible (best-effort assignment)
9. Generated schedule stored in reactive Alpine.js data structure
10. Algorithm completes in < 1 second for 30 students × 15 rounds

### Algorithm Specifications

[Source: architecture/components.md#Algorithm Engine, architecture/core-workflows.md]

**Greedy Fill Algorithm Pseudocode:**
```
for each round (1 to numRounds):
  assignedThisRound = new Set()
  for each team (1 to numTeams):
    // Assign 2 drivers
    driver1 = selectStudentForRole('driver', assignedThisRound)
    increment driver1.driverCount
    add driver1.id to assignedThisRound

    driver2 = selectStudentForRole('driver', assignedThisRound)
    increment driver2.driverCount
    add driver2.id to assignedThisRound

    // Assign 1 loader
    loader = selectStudentForRole('loader', assignedThisRound)
    increment loader.loaderCount
    add loader.id to assignedThisRound

selectStudentForRole(role, assignedThisRound):
  available = students.filter(s => !assignedThisRound.has(s.id))

  if (available.length === 0):
    console.warn('No available students - reusing students in same round')
    return students[0]  // Fallback for edge cases

  countKey = (role === 'driver') ? 'driverCount' : 'loaderCount'
  minCount = Math.min(...available.map(s => s[countKey]))
  candidates = available.filter(s => s[countKey] === minCount)

  return candidates[Math.floor(Math.random() * candidates.length)]
```

**Critical Algorithm Constraints:**
- **Independent Role Tracking:** NEVER combine driverCount and loaderCount into single counter - this breaks fairness for 2:1 ratio
- **No Duplicate Rounds:** Use Set to track assigned student IDs per round, filter them from selection
- **Random Tiebreaking:** When multiple students have same minimum count, use `Math.random()` for selection
- **Best-Effort Edge Cases:** If perfect balance impossible, log warning and continue with best-effort assignment
